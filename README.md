# Грант

Справочник и набор инструментов для выпускников школ стран СНГ, которые
поступают за рубеж на стипендию. Интерфейс на русском, архитектура готова к
добавлению других языков.

- Пошаговая установка GitHub, Supabase и Netlify — в [DEPLOY.md](DEPLOY.md).
- Дизайн-решения и обоснование — в [DESIGN.md](DESIGN.md).

## Что внутри

| Модуль | Маршрут | Что делает |
|---|---|---|
| Директория стипендий | `/scholarships`, `/scholarships/[slug]` | Карточки программ, честный разбор покрытия, чек-лист документов, пошаговая подача, история дат |
| Пошаговые гайды | `/guides`, `/guides/[slug]` | Статьи в markdown с поддержкой встроенных скриншотов |
| Трекер дедлайнов | `/deadlines` | Обратный отсчёт по каждой программе и календарь на весь год |
| Подбор стипендии | `/quiz` | Восемь вопросов, rule-based подбор с объяснением каждого совпадения |
| Калькулятор бюджета | `/budget` | Виза, перелёт, первый месяц на месте |
| Конвертер оценок | `/gpa` | Перевод между 5-, 10-, 12-, 100-балльной шкалами и GPA, двумя методами, плюс ECTS |

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS ·
Supabase (Postgres) · lucide-react · деплой на Netlify.

Версии Next.js и React держатся актуальными не для красоты: Netlify блокирует
деплой проектов на версиях с незакрытыми критическими уязвимостями. Проверить
состояние можно командой `npm audit` — она должна показывать ноль находок.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на http://localhost:3000. **Supabase для локального запуска не нужен**
— без переменных окружения сайт работает на данных из `data/scholarships.ts`
и `data/guides.ts`. Это сделано специально, чтобы можно было править контент
и дизайн без настройки базы.

## Настройка Supabase

### 1. Создай проект и выполни схему

Открой Supabase → SQL Editor → вставь содержимое
[`supabase/schema.sql`](supabase/schema.sql) и выполни. Скрипт идемпотентный,
его можно прогонять повторно.

Что создаётся:

- тип `coverage_type` — enum `full | partial | tuition_only`;
- таблица `scholarships` — программы. Слаг первичным ключом, сложные поля
  (`requirements`, `documents`, `steps`, `windows`, `budget`, `quiz`,
  `coverage_items`, `contact`) хранятся в `jsonb`, что позволяет менять форму
  данных без миграций;
- таблица `guides` — гайды, контент в поле `body` как markdown;
- RLS включён на обеих таблицах: анонимный ключ может только читать, запись
  доступна лишь service role;
- триггер `scholarships_touch` — автообновление `updated_at`.

### 2. Пропиши переменные окружения

Скопируй `.env.example` в `.env.local` и заполни:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...      # только для seed, в браузер не попадает
```

### 3. Залей начальные данные

```bash
npm run seed
```

Скрипт [`supabase/seed.ts`](supabase/seed.ts) загружает четыре стипендии
(Венгрия, Турция, Южная Корея, Китай) и пять гайдов из каталога
`data/`. Работает через `upsert` по `slug`, поэтому повторный запуск обновляет
строки, а не плодит дубли.

Дальше контент можно править двумя способами: прямо в Table Editor Supabase
(изменения подхватятся при следующей ревалидации, ISR стоит на час) или в
файлах `data/*.ts` с повторным `npm run seed`.

## Деплой

Подробная пошаговая инструкция — в [DEPLOY.md](DEPLOY.md): создание
репозитория, схема и seed в Supabase, импорт проекта в Netlify, переменные
окружения и разбор частых ошибок.

Коротко: Netlify определяет Next.js автоматически, в репозитории уже лежит
`netlify.toml` с официальным плагином `@netlify/plugin-nextjs`. В переменные
окружения добавляются `NEXT_PUBLIC_SUPABASE_URL` и
`NEXT_PUBLIC_SUPABASE_ANON_KEY`; `SUPABASE_SERVICE_ROLE_KEY` на хостинге не
нужен.

Проект собирается и на Vercel без изменений.

## Фотографии

Снимки подобраны вручную под каждую секцию и лежат в реестре `lib/photos.ts`
как id Unsplash. Ключ API не нужен: изображения отдаются напрямую с CDN
Unsplash, и картинка не меняется от пересборки к пересборке.

Добавить или заменить фото — это правка одной строки в `REGISTRY`. Ширина
файла задаётся параметром `width` в компоненте `<Photo>`, чтобы не тянуть
полноразмерные кадры в мелкие блоки.

Лицензия Unsplash не требует атрибуции, но ссылка на источник выводится под
каждым фото.

## Структура

```
app/                    маршруты App Router, по одной папке на модуль
components/             UI: шапка, лента дедлайнов, карточки, три калькулятора
data/                   начальные данные (они же фолбэк без Supabase)
lib/
  data.ts               единая точка доступа: Supabase с откатом на файлы
  dates.ts              окна подачи, обратный отсчёт, русские окончания
  markdown.tsx          рендер markdown в React без innerHTML
  match.ts              правила подбора стипендии
  photos.ts             реестр фотографий
  guide-covers.ts       обложки гайдов
  i18n.ts               словарный слой
messages/ru.json        строки интерфейса
supabase/               схема и seed-скрипт
```

## Добавление второго языка

Архитектура заложена, перевода пока нет.

1. Скопировать `messages/ru.json` в `messages/uz.json` и перевести значения.
2. Добавить `'uz'` в `LOCALES` и `DICTIONARIES` в `lib/i18n.ts`.
3. Обернуть `app/` в сегмент `app/[locale]/` и брать локаль из `params` —
   либо подключить `next-intl`, формат словаря с ним совместим, вызовы `t()`
   переписывать не придётся.
4. Контент переводится не в словаре, а колонками `name_uz`, `summary_uz`,
   `body_uz` в Supabase — они уже есть в схеме. `lib/data.ts` при этом
   выбирает переведённый вариант, если он заполнен, иначе русский.

## Чего сознательно нет в MVP

- Аккаунтов и логина. Прогресс квиза лежит в `localStorage`.
- Телеграм-бота с уведомлениями о дедлайнах.
- Перевода контента на другие языки.

## Про данные

Суммы и даты — ориентировочные, собраны на сентябрь 2026. Даты прошлых лет
взяты из истории кампаний, дата ближайшего окна во многих программах — прогноз
по закономерности прошлых лет, и в интерфейсе это подписано. Требования,
формы и списки документов меняются каждый сезон: единственный источник
истины — официальный портал программы.
