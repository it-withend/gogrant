# Дизайн-план

Стадия 1 из брифа: сначала решения, потом код. Ниже — что выбрано и почему,
плюс отдельная сверка с запретами брифа.

## Отправная точка

Сайт не про «образовательный стартап». Он про папку с документами: аттестат,
нотариальный перевод, апостиль, справка из банка, анкета с полями, консульская
печать, посадочный талон. Вся визуальная система собрана из этого предметного
мира — бланк, линовка, штамп, перфорация.

## Палитра

| Токен | HEX | Роль |
|---|---|---|
| `paper` | `#E6E7E1` | фон страницы. Холодная серо-зелёная бумага бланка. Намеренно НЕ тёплый крем |
| `plate` | `#FAFAF7` | поверхность карточек и таблиц — «вклеенный лист» поверх бумаги |
| `ink` | `#16191C` | основной текст, чёрная канцелярская паста |
| `ink-soft` | `#5A6068` | вторичный текст, подписи полей |
| `rule` | `#C6C8C0` | линовка: все границы — 1px hairline, теней нет вообще |
| `stamp` | `#1B4D8F` | консульские синие чернила. Ссылки, активные состояния, штамп обратного отсчёта |
| `seal` | `#9A2B2B` | сургучно-красный. Только дедлайны, срочность, «окно закрыто» |
| `amber` | `#8A5A12` | только маркер неполного покрытия гранта |

Синий `#1B4D8F` — не «стартаперский фиолетовый»: это цвет штемпельной подушки
визового отдела, и он работает функционально (все статусы «подано / одобрено»),
а не декоративно. Красный сургуч зарезервирован строго под время.

## Шрифты

- **Golos Text** — заголовки, интерфейс, основной текст. Гротеск Paratype,
  спроектированный для государственных сервисов и официальных форм. Выбран не
  за внешность, а за происхождение: это буквально шрифт анкеты, при этом
  современный и не казённый, с полноценной кириллицей. Роли: 700 для
  заголовков, 400/500 для текста.

  Первым кандидатом был Archivo, но у него нет кириллического набора — для
  русскоязычного сайта это дисквалификация, и замена оказалась содержательно
  точнее исходного выбора.
- **IBM Plex Mono** — даты, счётчики дней, коды программ, бейджи требований,
  номера шагов. Моноширинный здесь не украшение: цифры в трекере дедлайнов и в
  калькуляторах должны быть табличными и не прыгать при пересчёте.

Два семейства, обе роли функциональные. Inter/Roboto не взяты осознанно.

## Логика layout

- **Бланковая сетка.** Слева на широких экранах — вертикальная линовка и
  маркер секции в моноширинном (`§ 01`, `§ 02`). Это заменяет ALL-CAPS-надписи
  над заголовками.
- **Никаких теней.** Разделение — только 1px `rule` и смена фона `paper`/`plate`.
  Скругления 0–2px, одинаковые не везде: таблицы и плашки строго прямоугольные,
  скругление только у интерактивных полей ввода.
- **Плотность как у документа.** Данные подаются парами «поле → значение», а не
  абзацами маркетинга.

## Один смелый акцент

Трекер дедлайнов на главной — горизонтальная лента вроде отрывного посадочного
талона: перфорация точками между сегментами, каждая программа — сегмент с
круглой печатью обратного отсчёта (число дней синим штампом, с лёгким наклоном,
как настоящий оттиск). Лента скроллится горизонтально, у закрытых окон печать
красная сургучная. Вокруг неё всё остальное — дисциплинированная типографика.

## Анимация

Ровно один момент: при первой загрузке главной печати обратного отсчёта
«впечатываются» — короткий scale + доводка непрозрачности с небольшой задержкой
по сегментам. Больше нигде ничего не появляется при скролле.
Уважается `prefers-reduced-motion`.

## Иконки и фото

- Иконки — только `lucide-react`, строкой 1.5px, без заливок. Эмодзи нет нигде.
- Фото — Unsplash, подбор по смыслу секции через официальный API на этапе
  сборки (`lib/photos.ts`). Если ключ не задан, вместо фото рисуется
  типографская плашка с линовкой — не градиентный blob.

## Сверка с запретами брифа

| Запрет | Статус |
|---|---|
| Кремовый `#F4F1EA` + терракота `#D97757` | Фон холодный `#E6E7E1`, акцент — синий `#1B4D8F` |
| Тёмный фон + кислотный акцент | Светлая бумага |
| Одинаковые карточки + мягкая серая тень | Теней нет ни одной, границы hairline |
| Декоративные градиенты | Нет ни одного градиента |
| ALL-CAPS эйбрау над заголовками | Заменено на `§ NN` в моноширинном |
| Метки через middle dot | Разделитель — вертикальная линовка или перенос строки |
| «СЛОВО — фрагмент» с длинным тире | Заголовки — обычные фразы |
| Стрелка `→` в конце кнопок | Нет; у кнопок — конкретный глагол |
| Fade+slide-up на каждой секции | Один эффект, только на печатях в hero |
| Одно слово в заголовке другим цветом | Нет выделений внутри заголовков |
| Эмодзи вместо иконок | lucide-react |
